## Test Case 01 - Get current user with valid token (happy path)
Field	        | Content
Test Case ID    |TC-ME-001
Test Name	    |Get current user with valid token (happy path)
Module	        |Authentication - Me
Pre-conditions	|User `testuser@example.com` đã đăng ký và login thành công. Có JWT token hợp lệ.
Test Data	    |Header: `Authorization: Bearer <valid_jwt_token>`
Steps	
1. Login with `testuser@example.com` / `Test@1234` to get JWT token
2. Send GET request to /api/auth/me with header `Authorization: Bearer <token>`
3. Check response status code
4. Check response body contains user info (id, email, fullName)
Expected Results	
1. Status code: 200 OK
2. Response body contains: { "id": <number>, "email": "testuser@example.com", "fullName": "Nguyen Van A" }
3. Response does NOT contain password or passwordHash
Actual Results	
1. Status code: 200 OK
2. Response body contains: { "id": <number>, "email": "testuser@example.com", "fullName": "Nguyen Van A" }
3. Response does NOT contain password or passwordHash
